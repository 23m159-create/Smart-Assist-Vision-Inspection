# Smart Assist Vision Based Quality Inspection System

![System Overview]

Project Overview

The **Smart Assist Vision Based Quality Inspection System** is an automated quality inspection system developed for the inspection of filter components. The system integrates **machine vision, PLC-based automation, electro-pneumatic mechanisms, sensors, and HMI control** to perform multiple inspection operations with reduced manual intervention.

The system consists of **five inspection stations** designed to inspect different features of the filter component, including the **by-pass valve, O-ring, and stamping**. Based on the inspection results, the PLC controls the required sequence and supports sorting and rejection of defective components.

Project Type: College Team Project
Project Area: Industrial Automation, Machine Vision & Electro-Pneumatics
My Role: Electropneumatic & Automation



Problem Statement

Manual inspection of filter components can be time-consuming and may lead to inconsistent inspection results due to human error. Different features of a component also require different inspection methods.

The objective of this project was to develop an automated inspection system capable of:

* Performing multiple inspection operations in a single system
* Detecting defects using vision-based inspection
* Automating component movement and positioning
* Controlling inspection sequences using a PLC
* Using electro-pneumatic mechanisms for actuation
* Providing operator interaction through an HMI
* Separating or rejecting components based on inspection results

Inspection Stations

The system incorporates multiple inspection stages for the filter component.

Station 1 – Component Loading & Positioning

The component is loaded into the fixture and positioned for inspection.

Station 2 – By-Pass Valve Inspection

The by-pass valve is inspected to determine whether the required component condition is satisfied.

Station 3 – O-Ring Inspection

A vision-based inspection system is used to detect the presence and condition of the O-ring.

Station 4 – Stamping Inspection

The stamping operation or feature is inspected and verified.

Station 5 – Final Inspection & Sorting

The inspection results are processed by the control system, and the component is directed for the appropriate output, including rejection of defective components.


Working Principle

The overall operation follows:

Loading → Positioning → Inspection → Feedback → Decision → Sorting

1. The operator selects the required model through the **HMI**.
2. The component is loaded into the inspection fixture.
3. The PLC initiates the inspection sequence.
4. The rotary indexing mechanism moves the component between inspection stations.
5. Pneumatic cylinders position or actuate the required mechanisms.
6. Sensors provide position and operation feedback to the PLC.
7. The vision system performs the required visual inspection.
8. The inspection result is communicated to the control system.
9. The PLC evaluates the inspection result.
10. Based on the result, the component is accepted or rejected.
11. The defective component is directed to the rejection/sorting mechanism.
12. The system returns to its initial condition for the next component.
